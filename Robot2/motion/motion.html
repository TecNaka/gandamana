Ebook ini adalah referensi lengkap untuk Motion System robot humanoid Gandamana yang berlaga di KRSBI-H. Seluruh kode sumber berada di folder motion/src/ sebagai bagian dari ROS package kri2027.

Robot ROBOTIS OP3
Main Controller Intel NUC / Onboard Computer (ROS)
Sub-Controller OpenCR (STM32F4)
Aktuator Dynamixel MX-28/XL-320 (20 servo)

2.2 Dual Walk Profile Architecture

Kode motion Gandamana memiliki dua profile walking engine:

Profile Message Type Topic Digunakan di
Original OP3 Walk op3_walking_module_msgs/WalkingParam /robotis/walking/set_params driver.py, odometry.py, proses_noncom_nogyro.py
Quintic Walk (Custom) quintic_walk_msgs/WalkingParam /robotis/quintic_walk/set_params driver_baru_2025.py, odometry_baru_2025.py, odometry_bno.py

Beberapa file support kedua profile (driver_baru_2025.py, process_com_beta.py, projecttes.py) dengan konstanta PROFILE_QUINTIC.

2.3 Tiga Role Robot

Sistem menggunakan 3 peran yang ditentukan oleh Com_decision():

UTAMA --- Striker utama: follow_ball → positioning → kick
SECOND -- Pendukung: follow_ball → flank positioning
GOTO ---- Pemburu bola (tanpa nendang)

4.4 Game Status Handlers

INITIAL → READY

if STATE == "STATE_INITIAL":
    initgate += 1
    if initgate <= 1:
        Status = 'READY'

READY → PRE_POSITIONING_KICKOFF

if STATE == 'STATE_READY':
    readygate += 1
    if readygate <= 1:
        Status = 'PRE_POSITIONING_KICKOFF'

SET → PRE_STOP

if STATE == "STATE_SET":
    setgate += 1
    if setgate <= 1:
        Status = 'SET'  # langsung jadi PRE_STOP

PLAYING → PRE_RUN → RUN

if STATE == 'STATE_PLAYING':
    playgate += 1
    if playgate <= 1:
        Status = 'PRE_RUN'

FINISHED → PRE_STOP

if STATE == 'STATE_FINISHED':
    finishgate += 1
    if finishgate <= 1:
        Status = 'PRE_STOP'

4.6 Com_decision() — Role Assignment

def Com_decision():
    Alur:
    1. Jika ada robot dengan Taskcom="kck" → SECOND (hindari double-kick)
    2. Jika ball_size ≥ threshold:
       - Robot dengan ball_size terbesar → UTAMA
       - Lainnya → SECOND
    3. Jika ball_size ≥ range:
       - Bandingkan yaw_fixed2 vs posw robot lain
       - Yang lebih kecil offset yaw ke goal → UTAMA
    4. Jika self fallen → SECOND
    5. Jika teammate fallen → UTAMA
    6. Jika ada yang "rt" atau "posbl" → SECOND
    7. Jika tidak ada koneksi → UTAMA (standalone)

4.7 Task Flow UTAMA (Detail)

Task initial (baris 1537-1559)

- count_task += 1 tiap 1000ms
- Motion_Start(), start_tracking(True), OdomStart()
- Jika check_ball_lost(10): walk_follow_head dengan amove dari pan
- Jika tidak: jalan lurus
- setelah 3 siklus (count_task > 2) → Task = 'follow_ball'

Task follow_ball (baris 1561-1594)

- Com_decision() tiap siklus
- Taskcom = "fb"
- xmove, ymove, amove = walk_follow_head(pan_present, tilt_present)
- walking(xmove, ymove, amove, 0.63)
- If tilt_degree < -60 → Task = 'heading_to_goal_first'
- Jika ball lost 20 frame: scanning (rotasi acak kiri/kanan)

Task heading_to_goal_first (baris 1596-1619)

- Jika ball lost → kembali ke follow_ball
- Jika yaw_fixed2 dalam ±5° dari goal_orientation:
  → Goalposition(JERSEY), Task = 'positioning_kick'
- Jika tidak: walk_rotate2(goal_orientation)

Task positioning_kick (baris 1621-1674)

- Goalposition(JERSEY) untuk update goal_orientation
- Jika yaw dalam ±10°:
  - walk_ball_position_to_kick(target_pan=1.0, target_tilt=-74, heading)
  - Syarat located: delta_pan<2, delta_tilt<13, ball_size>4000
  - count_goal_found > 2 → kick_ball
- Jika yaw di luar toleransi: walk_rotate22(goal_orientation)
- Jika ball lost: scanning, Task kembali ke heading_to_goal_first

Task kick_ball (baris 1676-1712)

- OdomStop()
- ball_x_angle < 0 → action 230 (Right Kick)
- ball_x_angle > 0 → action 225 (Left Kick)
- Taskcom = "kck"
- Setelah kick: Motion_InitWalking(), Motion_Start()
- Task kembali ke 'initial'

Task get_up (baris 1713-1735)

- OdomStop()
- fallen_forward → action 122 (bangun depan)
- fallen_backward → action 66 (bangun belakang)
- Setelah bangun → walk_ready → initial

4.8 Walk Functions

walk_follow_head (baris 848)

pan_degree → a_move (map -89..89 ke -15..15)
abs(a_move) → x_move (map 0..15 ke 20..0)
tilt_degree → x_move_tilt (map tilt_min..0 ke x_move..-0.008)
return x_move_tilt*0.001, 0, a_move  # x dalam meter

walk_ball_position_to_kick (baris 1199)

target_pan=1.0, target_tilt=-74
delta_pan = target_pan - pan_degree
delta_tilt = target_tilt - tilt_degree

x_move dari delta_tilt_pan (delta_tilt + abs(delta_pan)*0.3)
y_move dari pan_degree vs target_pan
a_move dari Heading_Gap(heading, yaw_fixed2)

located = (delta_pan > -2 dan < 2) dan delta_tilt < 13 dan ball_size > 4000

walk_to_position (baris 864)

distance = sqrt((x - X_global)² + (y - Y_global)²)
gap = Heading_Gap(goal_orientation, yaw_fixed2)

Mode 'move':
  - a_move = map(gap, -180..180, -15..15)
  - x_move dari abs(a_move) dan distance
  - y_move = PID(gap, 0) / 30 (clamp ±15)
  - Jika X dalam ±6 dari target → mode 'netral'

Mode 'netral':
  - x_move = -4 (mundur sedikit)
  - Rotasi halus ke target heading
  - Jika yaw dalam ±6° dari target → in_position = True

walk_rotate2 (baris 932)

heading_gap = Heading_Gap(heading, yaw_fixed2)
delta_tilt = -57 - tilt_degree

x_move dari delta_tilt (maju/mundur biar dapet sudut pandang)
y_move = PID(heading_gap, 0) / 30 (clamp ±15)
a_move = map(pan_degree, -10..10, -6..6)

4.9 Utility Functions

Heading_Gap (baris 815)

Menghitung selisih sudut terpendek antara goal dan yaw.
Handle kasus跨越 0°/180° boundary:
- Jika goal positif dan yaw negatif (atau sebaliknya):
  Hitung gap via 0° dan via 180°, pilih yang lebih pendek
- Lainnya: gap = goal_orientation - yaw_fixed2

calculate_pid (baris 723)

kp = 8.0, ki = 5.0, kd = 15.0
error = set_point - val
rateError = error - lastError
out = kp*error + kd*rateError  # (ki tidak dipakai - dikomentari)

map_value vs map_value2

map_value:  Dengan clamping (nilai dibatasi min/max source)
map_value2: Tanpa clamping (bisa di luar range)

check_ball_lost (baris 793)

Counter: setiap frame tanpa bola → ball_was_lost++
Jika ball_was_lost ≥ threshold → return 1 (lost)
Jika bola ketemu → reset counter

10. ODOMETRY SYSTEM

10.1 Prinsip Dead-Reckoning

Odometry Gandamana menggunakan kinematika kaki (forward kinematics) untuk menghitung perpindahan robot. Tidak menggunakan visual odometry atau encoder roda.

Setiap langkah:
1. Baca sudut joint kaki → ForwardOdom() → displacement (X, Y, Angle)
2. Akumulasi ke posisi global → position()
3. Kirim ke process.py via Pose2D

Forward Kinematics (ForwardOdom)

P = 12    # paha (cm)
B = 12    # betis (cm)
K = 3.05  # telapak kaki (cm)

def ForwardOdom(PG, LT, GL):
    # PG = pinggul, LT = lutut, GL = kaki
    Hr = P*cos(PG) + B*cos(PG+LT) + K*cos(PG+LT-GL)   # tinggi kaki kanan
    Hl = P*cos(-PG) + B*cos(-PG-LT) + K*cos(-PG-LT+GL) # tinggi kaki kiri
    Xr = P*sin(PG) + B*sin(PG+LT) + K*sin(PG+LT-GL) - x_offset
    Xl = P*sin(-PG) + B*sin(-PG-LT) + K*sin(-PG-LT+GL) - x_offset
    return Hr, Hl, Xr, Xl

Side Kinematics (SideOdom)

def SideOdom(PG, GL, PB):
    base = PB * sin(-PG)
    step = K * sin(-PG + GL)
    Yr = base + step - y_offset/2
    Yl = base + step + y_offset/2
    return Yr, Yl

Angle Kinematics (AngleOdom)

def AngleOdom(Rpg, Lpg):
    Angle = abs(Rpg) + abs(Lpg)
    return Angle

XMove & YMove (Akumulasi Displacement)

def XMove(Swap, Move, Angle):
    noise = 1.3
    swapX = -Swap
    X = moveX + swapX + noise
    moveX = Move
    return X, Angle

def YMove(supportY, swingY, Angle):
    Y = swingY - supportY
    return Y, Angle

Position Accumulation

def position(X, Y, W):
    W_global = deg2rad(W_global)
    # XMOVE
    X_global += X * cos(W_global)
    Y_global -= X * sin(W_global)
    # YMOVE
    X_global += Y * cos(pi/2 + W_global)
    Y_global -= Y * sin(pi/2 + W_global)
    position_Pub(X_global, Y_global, rad2deg(W_global))

17.3 Common Issues & Solutions

Robot Jalan Miring

Penyebab: init_y_offset atau balance_hip_roll_gain salah
Solusi: Tuning init_y_offset (positif = koreksi ke kiri)
        Naikkan balance_hip_roll_gain untuk koreksi otomatis

Robot Sering Jatuh ke Depan

Penyebab: hip_pitch_offset terlalu kecil
Solusi: Naikkan hip_pitch_offset (15° → 18°)
        Turunkan x_move_amplitude

Robot Tidak Merespon Vision

Penyebab: tracking_state tidak "start"
          ball_state callback error
Solusi: Cek start_tracking(True) dipanggil
        Cek /DEWO/.../ball_state topic

Odometry Drift Cepat

Penyebab: Noise pada FK, walking di permukaan tidak rata
Solusi: Gunakan odometry_bno.py (dengan IMU feedback)
        Tambah periode update

Double Kick (2 Robot Nendang Bersamaan)

Penyebab: Com_decision() tidak filter Taskcom="kck"
Solusi: Pastikan baris 453-458 aktif:
        if Taskcom == "kck": robotstatus = "SECOND"
